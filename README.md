Инструкции по запуску:

Загрузите код MicroPython на ESP32/ESP8266:
Убедитесь, что у вас есть прошивка MicroPython на вашей плате.
Установите необходимые библиотеки (dht и urequests) с помощью upip.
Загрузите micropyserver.py на ESP
Замените YOUR_WIFI_SSID, YOUR_WIFI_PASSWORD и YOUR_FLASK_SERVER_IP на ваши данные.
Запустите сервер Flask на вашем компьютере:
Сохраните server_web.py в корень проекта; index.html и history.html в  подпапке templates.
Установите Flask: pip install Flask.
Запустите сервер: python server_web.py.
Откройте веб-браузер:
Перейдите по адресу, указанному в консоли Flask (http://127.0.0.1:5000 или http://YOUR_COMPUTER_IP:5000) - увидите текущие показание датчика.
http://xxx.xxx.xxx.xxx:5000/history_data - данные с показаниями за период.
Как это работает:

MicroPython на ESP32/ESP8266 считывает данные с датчика DHT22.
Эти данные преобразуются в JSON и отправляются на Flask сервер по HTTP POST.
Сервер Flask принимает JSON данные, сохраняет их в latest_data.
Когда вы открываете веб-страницу, Flask рендерит index.html с последними полученными данными.
Веб-страница отображает температуру и влажность.

Важные моменты:

Замените плейсхолдеры: Замените YOUR_WIFI_SSID, YOUR_WIFI_PASSWORD, YOUR_FLASK_SERVER_IP и номер DHT-пина на ваши данные.
Убедитесь, что устройства в одной сети: ESP32/ESP8266 и компьютер с Flask должны находиться в одной Wi-Fi сети.
Периодичность отправки данных: В коде MicroPython установлена задержка в 60 секунд, но можете ее изменить по вашему желанию
